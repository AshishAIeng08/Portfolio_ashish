# Role-specific resume setup

Add your editable PDF resumes to this folder with these exact filenames:

- `resume-software-engineer.pdf`
- `resume-frontend-developer.pdf`
- `resume-devops-engineer.pdf`
- `resume-data-analyst.pdf`

The portfolio deliberately displays a setup message until these PDFs exist, preventing broken or misleading downloads. Keep every resume factual and aligned with the verified experience in `lib/data.ts`.
